# exch — бот-обменник CryptoBot ⇄ xRocket

Клиент присылает боту чек CryptoBot или xRocket (или ссылку на счёт) — бот забирает чек
аккаунтом-юзерботом и сразу выдаёт чек другого кошелька или оплачивает счёт. Комиссия, лимиты,
резерв и паузы — в админ-панели внутри того же бота; деньги — в учёте с двойной записью,
сверка с кошельками — сама.

Написан на Rust, данные — в PostgreSQL. Одна программа `exch`: движок, юзербот, бот для
клиентов и пульт владельца.

## Быстрый старт (ноутбук или сервер)

Нужен PostgreSQL 16. Для первого запуска на Windows скачайте `exch-windows` из последнего
успешного прогона рабочей ветки, распакуйте комплект и откройте `exch.exe`.
Расположение сборки и зависимости описаны в [инструкции для Windows](docs/DEPLOY.md).

Для сборки из исходников нужен Rust.

```sh
cargo build --release          # в папке проекта; база для сборки не нужна
target/release/exch            # Windows: дважды щёлкните target\release\exch.exe
```

Первый запуск сам откроет мастер настройки — по шагам и с проверкой каждого ответа:

1. **База** — пароль `postgres`; база `exch` и таблицы создаются сами.
2. **Бот** — токен от @BotFather (проверяется сразу).
3. **Владелец** — откройте одноразовую ссылку из окна мастера со своего аккаунта Telegram,
   нажмите Start и подтвердите показанный ID в мастере. Можно ввести свой ID вручную.
4. **Telegram API** — `api_id` и `api_hash` с my.telegram.org.
5. **Ключ сессий** — создаётся сам.
6. **Юзербот** — телефон отдельного аккаунта, код и облачный пароль. Можно подключить два
   аккаунта, по одному на кошелёк, или один на оба кошелька.

Потом мастер предложит сразу запустить бота. Напишите ему `/start`: в меню будет
«Админ-панель» — её видите только вы и персонал.

## Каждый день

| Что | Как |
|---|---|
| Запустить | `target/release/exch` (двойной щелчок по `exch.exe`) — работает, пока открыто окно |
| Остановить | Ctrl+C; начатые заявки бот доведёт при следующем запуске |
| На сервере | службой Windows: `exch service install` (из PowerShell от администратора), затем `exch service start` / `stop` / `status` — [`docs/DEPLOY.md`](docs/DEPLOY.md) |
| Проверить всё | `exch check` — ✅ готово, ⚠️ стоит поправить, ❌ не заработает |
| Поменять настройку | `exch setup` (можно повторять) или Блокнотом `.env` / `config.toml`, затем перезапуск |
| Обновить | по [`docs/RUNBOOK.md`](docs/RUNBOOK.md), «Обновление exch и откат»: «Обслуживание» в пульте → `exch backup` → прежний `exch.exe` переименовать в `exch.prev.exe`, новый — на его место → запуск → `exch check` → «Самопроверка» → «Обслуживание» выкл |
| Что-то случилось | [`docs/RUNBOOK.md`](docs/RUNBOOK.md) — «что делать, если…»: разбор заявки, недостача, вход сброшен, стоп-кран и др. |

## Настройки

- **`.env`** — только секреты: пароль базы, токен бота, ваш ID, данные Telegram API, ключ
  сессий. Пишет мастер; образец — [`.env.example`](.env.example). Никому не пересылайте.
- **`config.toml`** — остальное: часовой пояс, контакт поддержки, вид логов, пинг-сервис.
  Образец с пояснениями — [`config.example.toml`](config.example.toml).
- Переменные окружения с теми же именами сильнее обоих файлов (так настраивается сервер).
- Комиссии, лимиты, направления, резерв, эмодзи — в админ-панели, без перезапуска.
  Общий коэффициент задаётся в «Направления → Рычаг», границы комиссии — в карточке направления.

Файлы ищутся в папке, откуда запущен `exch`, а если там их нет — в папке программы и на два
уровня выше (`target/release` → корень проекта).

## Команды

`exch` без команды — запуск (первый раз — мастер). Остальное — подробности в `exch --help`:

| Команда | Что делает |
|---|---|
| `exch setup` | Мастер настройки; можно повторять (войти заново, перенести кошелёк) |
| `exch check` | Проверить всё: ✅ / ⚠️ / ❌ |
| `exch demo` | Бот и пульт на симуляторе кошельков, без денег, на отдельной базе |
| `exch backup` / `exch backup --check` | Копия базы сейчас / проверить последнюю копию |
| `exch restore <файл>` | Восстановить базу из копии (только в пустую базу) |
| `exch service install / start / stop / status / uninstall` | Служба Windows |
| `exch login` | Войти аккаунтом юзербота и привязать кошелёк |
| `exch selftest` | Чек туда и обратно на каждом кошельке (при остановленном exch; в пульте — «Самопроверка») |
| `exch migrate` | Применить изменения базы и выйти |
| `exch emoji …`, `exch avatar <файл>` | Премиум-эмодзи и живая аватарка бота |
| `exch record`, `exch listen` | Запись ответов ботов кошельков для разработчика |

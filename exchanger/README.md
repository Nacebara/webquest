# exch — бот-обменник CryptoBot ⇄ xRocket

Клиент присылает боту чек CryptoBot или xRocket (или ссылку на счёт) — бот забирает чек
аккаунтом-юзерботом и сразу выдаёт чек другого кошелька или оплачивает счёт. Комиссия, лимиты,
резерв и паузы — в админ-панели внутри того же бота; деньги — в учёте с двойной записью,
сверка с кошельками — сама.

Написан на Rust, данные — в PostgreSQL. Одна программа `exch`: движок, юзербот, бот для
клиентов и пульт владельца.

## Быстрый старт (ноутбук или сервер)

Нужны PostgreSQL 16 (пароль пользователя `postgres` вы задали при установке) и Rust.

```sh
cargo build --release          # в папке проекта; база для сборки не нужна
target/release/exch            # Windows: дважды щёлкните target\release\exch.exe
```

Первый запуск сам откроет мастер настройки — по шагам и с проверкой каждого ответа:

1. **База** — пароль `postgres`; база `exch` и таблицы создаются сами.
2. **Бот** — токен от @BotFather (проверяется сразу).
3. **Владелец** — напишите боту любое сообщение, мастер сам узнает ваш ID.
4. **Telegram API** — `api_id` и `api_hash` с my.telegram.org.
5. **Ключ сессий** — создаётся сам.
6. **Юзербот** — телефон отдельного аккаунта, код и облачный пароль; один вход — оба кошелька.

Потом мастер предложит сразу запустить бота. Напишите ему `/start`: в меню будет
«Админ-панель» — её видите только вы и персонал.

## Каждый день

| Что | Как |
|---|---|
| Запустить | `target/release/exch` (двойной щелчок по `exch.exe`) — работает, пока открыто окно |
| Остановить | Ctrl+C; начатые заявки бот доведёт при следующем запуске |
| Проверить всё | `exch check` — ✅ готово, ⚠️ стоит поправить, ❌ не заработает |
| Поменять настройку | `exch setup` (можно повторять) или Блокнотом `.env` / `config.toml`, затем перезапуск |
| Обновить | новые файлы проекта → `cargo build --release` → перезапуск (новые таблицы применятся сами) |

## Настройки

- **`.env`** — только секреты: пароль базы, токен бота, ваш ID, данные Telegram API, ключ
  сессий. Пишет мастер; образец — [`.env.example`](.env.example). Никому не пересылайте.
- **`config.toml`** — остальное: часовой пояс, контакт поддержки, вид логов, пинг-сервис.
  Образец с пояснениями — [`config.example.toml`](config.example.toml).
- Переменные окружения с теми же именами сильнее обоих файлов (так настраивается сервер).
- Комиссии, лимиты, направления, резерв, эмодзи — в админ-панели, без перезапуска.

Файлы ищутся в папке, откуда запущен `exch`, а если там их нет — в папке программы и на два
уровня выше (`target/release` → корень проекта).

## Команды

`exch` без команды — запуск (первый раз — мастер). Остальное: `exch setup`, `exch check`,
`exch migrate`, `exch login`, `exch selftest`, `exch emoji …`, `exch record`, `exch listen` —
подробности в `exch --help`.

## Выжимка правил задания (полный текст — `OWNER-BRIEF.md`)

- Не верить документам: «сделано» — заявление. Вывод о коде — только по открытому коду, о живом
  поведении — только по логу, ответу Telegram или скриншоту владельца.
- Находка = доказательство (файл:строка, тест, живой ответ) + тяжесть 0–4 + сценарий с числами +
  что сделать + цена (S до 2 часов, M до дня, L больше). Помечать: «запуском», «вживую», «чтением».
- Доказать запуском можно временным тестом `crates/<крейт>/tests/zz_audit_<имя>.rs`: запустить,
  вывод — в находку, файл удалить. В конце `git status --short` пуст.
- Решение Р2 окончательное (только юзербот, API кошельков не предлагать). Docker для exch не
  предлагать. Схема базы — только новыми миграциями. Тесты не ослаблять.
- Противоречие документов — записать и спросить владельца, молча не чинить.
- Секреты не просить и не повторять. Git: коммит после шага, сразу отправка, без `--force`.
- Владельцу — по-русски, просто, сначала результат; вопросы — с вариантами и рекомендацией.

## Среда после старта сессии

```bash
service postgresql start && su postgres -c "psql -qc \"ALTER USER postgres PASSWORD 'dev'\""
export DATABASE_URL=postgres://postgres:dev@localhost:5432/exch
cd exchanger && sqlx database create && sqlx migrate run --source migrations
cargo test -p engine --all-features <фильтр>   # первый запуск собирает проект ~3 минуты
```

  `cargo install sqlx-cli --version 0.9.0 --locked --no-default-features --features postgres,rustls`.
  Для чтения кода и запуска тестов он не нужен, только для `cargo sqlx prepare --check`.
- Исходное состояние (коммит `692211e`, 10 ноября): fmt, clippy, sqlx — чисто, 601 тест зелёный.
  С тех пор менялись только документы — весь набор заново гонять не нужно.
- Telegram (только заходы про интерфейс): среда «webquest» пускает к `api.telegram.org`. Токен
  тестового бота @fexchbot попросить у владельца заново (в новой среде его нет), ID владельца — из
  `getUpdates` после его `/start`. Оба — в локальный `exchanger/.env`. Запуск из `exchanger/`:
  `TELEGRAM_PROXY="$HTTPS_PROXY" TELEGRAM_CA_FILE=/root/.ccr/ca-bundle.crt target/debug/exch demo`.
  Премиум-эмодзи для демо (пока не исправлена Ж-2) — загрузить в основную базу перед запуском:
  `psql … -d exch -c "INSERT INTO settings(key,value) VALUES ('emoji_packs', '<содержимое tools/emoji/demo-packs.json>'::jsonb) ON CONFLICT (key) DO UPDATE SET value = EXCLUDED.value"`.

# exch на сервере Windows (рядом с гарантом)

Боевой запуск: тот же компьютер с Windows, где работает гарант. exch — одна программа
`exch.exe`, база — PostgreSQL 16 (служба Windows), запуск — встроенная служба `exch`.
Пробу на ноутбуке описывает `LAPTOP.md`; что делать при сбоях — `RUNBOOK.md`.

Секреты (токен бота, пароль базы, ключи Telegram) — только в `.env` на сервере: не в чатах, не в
переписке, не в облаке. Сохраните копию `.env` в менеджер паролей: копии базы зашифрованы ключом
`SESSION_KEY` из него — без `.env` базу из копии не поднять вовсе (Б-19.1).

## 0. Что понадобится

| Что | Где взять |
|---|---|
| PostgreSQL 16 | postgresql.org → Windows installer; служба `postgresql-x64-16` запущена, пароль пользователя `postgres` записан |
| Комплект для Windows | GitHub → Actions → exchanger-ci → последний зелёный прогон ветки → артефакт **exch-windows** |
| Microsoft Visual C++ x64 | Для запуска нужен `VCRUNTIME140.dll`. Если Windows сообщает, что файл отсутствует, установите [Visual C++ Redistributable x64](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist) |
| Бот | @BotFather → `/newbot` → токен. Бот один: клиенты и ваш пульт в нём же. Включите `/setinline` |
| `api_id`, `api_hash` | my.telegram.org → API development tools (одно приложение на все аккаунты) |
| Два аккаунта Telegram для юзерботов (или один) | отдельные номера с облачным паролем; руками ими не пользоваться. Два — советую: ограничение одного не остановит второй кошелёк |
| В CryptoBot у каждого аккаунта — «Лимит без код-пароля» | CryptoBot → Кошелёк → Настройки → Безопасность |
| Внешний сторож для боевого запуска | healthchecks.io → проверка с периодом 1 мин, уведомления в Telegram → адрес пинга |

## 1. Папка

Распакуйте комплект в `C:\exch`. В этой папке должны лежать `exch.exe`, `assets\emoji` и `docs`.
Для установки из исходников выполните `cargo build --release` и скопируйте туда `exch.exe` из
`target\release`, а также `assets\emoji` и `docs`. После настройки рядом с `exch.exe` появятся
`.env`, `config.toml`, папки
`logs` (журнал по дням) и `backups` (копии базы). Гарант живёт в своей папке и не мешает:
exch не открывает входящих портов (только исходящие запросы к Telegram), память — десятки МБ.

## 2. Настройка

PowerShell в `C:\exch`:

```
.\exch.exe setup
```

Мастер по шагам: пароль `postgres` (база `exch` создаётся сама) → токен бота → откройте
одноразовую ссылку из окна мастера со своего аккаунта Telegram, нажмите Start и подтвердите ID
в мастере → `api_id`, `api_hash` → ключ шифрования сессий
(создаётся сам) → вход юзерботами: «Кошельки — на двух разных аккаунтах?» — **д**, затем телефон,
код и облачный пароль для CryptoBot, потом для xRocket (другой номер). В конце мастер предложит
запустить бота — ответьте **н**: дальше запуск службой.

```
.\exch.exe check
```

Все строки ✅ или понятные ⚠️ (например, «копий ещё нет»).

## 3. Настройки в `config.toml` (Блокнотом)

- `[owner] timezone` — ваш часовой пояс; `support` — @username оператора поддержки.
- `[health] url` — адрес пинга healthchecks.io: exch пингует раз в минуту, только когда движок
  и опрос Telegram живы. Перестал — сервис пишет вам.
- `[backup] dir` — папка копий; лучше облачная (Яндекс Диск, OneDrive), например
  `C:\Users\<вы>\YandexDisk\exch-backups`. Время копии — `at` (по умолчанию 04:30).

После правки — `.\exch.exe service stop`, затем `.\exch.exe service start`.

## 4. Служба

PowerShell **от имени администратора** в `C:\exch`:

```
.\exch.exe service install
```

```
.\exch.exe service start
```

Служба `exch` запускается вместе с компьютером (после PostgreSQL и сети), при сбое
перезапускается сама (через 10 с, 30 с, 60 с), останавливается мягко — начатые заявки
доводятся. Проверить: `.\exch.exe service status` и `.\exch.exe check`; журнал — `logs`.
Перезагрузите компьютер один раз и убедитесь, что поднялись и гарант, и exch (`check`, `/start`
боту).

Удалить службу: `.\exch.exe service uninstall`.

## 5. Пульт: первая настройка

Напишите боту `/start` → «Админ-панель».

1. **Капитал.** Пополните кошельки юзерботов в CryptoBot и xRocket → «Сверить балансы» →
   «Это мой взнос: провести».
2. **Направления** после установки закрыты: карточка направления → лимиты → «Открыть приём».
3. **Самопроверка** («Аккаунты») — на каждом кошельке чек на 1 USDT и его же активация.
4. **Премиум-эмодзи**. Подключите готовые публичные значки обменника командами ниже.
   `emoji show` покажет 127 анимированных и 127 статичных значков.

   ```powershell
   .\exch.exe emoji adopt --from '@Kazinakabot'
   .\exch.exe emoji adopt --from '@exchgay'
   .\exch.exe emoji show
   ```

   Для создания наборов у своего бота есть команда `.\exch.exe emoji install --owner <ваш ID>`.
5. **Сотрудники** — «Сотрудники» → добавить (оператор, админ).
6. Первая копия базы — `.\exch.exe backup` (сразу проверится восстановлением).
7. Установить живую аватарку бота — `.\exch.exe avatar docs\mockups\logo\avatar.mp4`.

## 6. Первый живой прогон (по 1 USDT)

Вы — сотрудник, поэтому ссылку на чек, присланную вами, пульт открывает как карточку, а не как
обмен (защита от ошибки сотрудника). Чтобы обменять самому: пришлите ссылку → «Обменять как
клиент» → пришлите её ещё раз в течение 2 минут. Сценарий прогона — веха 9 плана.

## 7. Обновление, откат, сбои

Обновление и откат — `RUNBOOK.md`, «Обновление exch и откат» (обслуживание → копия → замена
`exch.exe` → проверка). Вход юзербота сброшен, аккаунт заблокирован, компьютер сломался —
там же.

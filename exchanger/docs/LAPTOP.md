# exch на ноутбуке (Windows 10/11)

Вся система — движок, клиентский бот и пульт — это один файл `exch.exe`. Пока окно с ним
открыто и ноутбук в сети, боты работают. Закрыли окно — остановились; начатые заявки бот
доведёт при следующем запуске, деньги не теряются.

## 1. Один раз: PostgreSQL

1. https://www.postgresql.org/download/windows/ → Download the installer → версия **16**.
2. Установка с настройками по умолчанию, порт **5432**. Придумайте пароль пользователя
   `postgres` из латинских букв и цифр (без `@ : / ?`) и запомните его.
3. В конце снимите галочку Stack Builder — он не нужен. Базу `exch` бот создаст сам.

## 2. Один раз: что подготовить

| Что | Где |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | my.telegram.org → войти номером → API development tools → создать приложение |
| Два бота: клиентский и пульт | @BotFather → `/newbot` дважды → два токена |
| Ваш Telegram ID | @userinfobot |
| Аккаунт юзербота | отдельный номер; включён облачный пароль; в CryptoBot: Кошелёк → Настройки → Безопасность → «Лимит без код-пароля» (по умолчанию бот считает 500 $) |

## 3. Установка

1. Распакуйте архив в папку **без русских букв** в пути, например `C:\exch`.
2. Дважды щёлкните **`0-key.bat`** — появится строка `SESSION_KEY=…`. Скопируйте её.
3. Откройте **`.env`** Блокнотом (правый щелчок → Открыть с помощью → Блокнот), впишите пароль
   PostgreSQL, свой ID, ключи и токены, вставьте строку `SESSION_KEY=…`. Сохраните.
   `.env` и ключ — секреты: никому не пересылайте и не вставляйте в чаты.
4. **`1-check.bat`** — покажет, чего ещё не хватает.
5. **`2-database.bat`** — создаст базу и таблицы.
6. **`3-login.bat`** — вход аккаунтом юзербота: телефон в формате `+7…`, код из Telegram,
   облачный пароль. Второй вход (кошелёк xRocket) код уже не спросит.
   После входа этим аккаунтом руками не пользуйтесь и не запускайте `exch` одновременно на
   двух компьютерах.

Windows может показать «Система Windows защитила ваш компьютер» — файл не подписан:
«Подробнее» → «Выполнить в любом случае». Если ругается антивирус — добавьте папку в
исключения.

## 4. Запуск

- **`4-run.bat`** — бот работает, пока открыто окно. Остановка — **Ctrl+C** (дождитесь `stopped`).
- Напишите `/start` обоим ботам со своего аккаунта. Пульт отвечает только вам.
- Один раз — премиум-эмодзи: **`5-emoji.bat`**, введите свой Telegram ID (до этого нажмите
  `/start` в клиентском боте).
- Отключите сон ноутбука при работе от сети: уснул — боты молчат до пробуждения.

## 5. Пульт: первая настройка

1. **Капитал.** Пополните кошельки юзербота в CryptoBot и xRocket. Через ≤ 10 минут придёт
   «Баланс … не сходится: +N» → «Это мой взнос: провести». Сразу: «Сводка» → «🔁 Сверить балансы».
2. **Цели резерва.** «Встречный поток» → «Цель: CryptoBot», «Цель: xRocket» — рабочий объём кошельков.
3. **Направления** после установки закрыты: карточка → «Лимиты» (для теста — `1 300`) →
   «▶️ Открыть приём».
4. **Самопроверка:** «Сводка» → «🧪 Самопроверка» — на каждом кошельке чек на 1 USDT и его
   же активация. Всё ✅ — можно принимать. (`selftest.bat` — то же, но только при закрытом
   `4-run.bat`.)

## 6. Первый живой прогон (по 1 USDT)

Со **своего** аккаунта (не юзербота):

| Что | Как | Ожидаем |
|---|---|---|
| CryptoBot → xRocket | `@send 1usdt` → чек → ссылку клиентскому боту | чек xRocket и кнопка «Забрать» |
| xRocket → CryptoBot | `@xrocket 1` → чек USDT → ссылку боту | чек CryptoBot |
| Оплата счёта xRocket / CryptoBot | счёт на 1 USDT → ссылку боту → прислать чек на сумму из ответа | «Счёт оплачен» |
| Отказ | уже активированный чек | «чек уже активирован», деньги не тронуты |

После прогона: «Сводка» — разбор пуст, «Сверить балансы» — всё сходится. Если что-то не так —
заявка в «Разборе» с причиной и ответами кошелька, решения — кнопками.

## 7. Обновление

Пришлю новый `exch.exe`: закройте `4-run.bat` (Ctrl+C), замените файл, запустите
`2-database.bat`, затем `4-run.bat`.

## 8. Частые проблемы

| Сообщение | Что делать |
|---|---|
| `cannot connect to PostgreSQL` | PostgreSQL не запущен (Службы → postgresql-x64-16 → Запустить) или пароль в `DATABASE_URL` неверный |
| `required environment variable … is not set` | заполните эту строку в `.env` |
| `cannot read .env` | в `.env` опечатка — строка должна быть вида `ИМЯ=значение` |
| бот не отвечает | окно `4-run.bat` закрыто или ноутбук уснул |

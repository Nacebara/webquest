# exch на ноутбуке (Windows 10/11)

Вся система — одна программа `exch.exe` в папке проекта. Пока окно с ней открыто и ноутбук в
сети, бот работает. Закрыли окно — остановился; начатые заявки бот доведёт при следующем
запуске, деньги не теряются.

## 1. Один раз: что нужно

| Что | Где |
|---|---|
| PostgreSQL 16 | установлен, служба `postgresql-x64-16` запущена; пароль пользователя `postgres` — тот, что задали при установке |
| Rust | rustup.rs; нужная версия подтянется сама при сборке |
| Бот | @BotFather → `/newbot` → токен. Бот один: клиенты и ваша админ-панель в нём же |
| `api_id`, `api_hash` | my.telegram.org → API development tools → создать приложение |
| Аккаунт юзербота | отдельный номер с облачным паролем; руками им потом не пользуйтесь |

## 2. Сборка

В папке проекта (Windows Terminal, PowerShell или cmd):

```
cargo build --release
```

База для сборки не нужна. Программа появится в `target\release\exch.exe`.

## 3. Первый запуск

Дважды щёлкните `target\release\exch.exe`. Откроется мастер настройки — шесть шагов, каждый
ответ проверяется сразу, всё сохраняется в `.env` и `config.toml` в папке проекта:

1. пароль `postgres` → база `exch` и таблицы создаются сами;
2. токен бота → бот проверяется;
3. напишите боту любое сообщение → мастер узнаёт ваш ID;
4. `api_id` и `api_hash`;
5. ключ шифрования сессий — создаётся сам;
6. вход юзерботом: телефон `+7…`, код из Telegram, облачный пароль — сразу для CryptoBot и
   xRocket (второй раз код не спросит).

В конце мастер предложит запустить бота. Прервали посередине — запустите `exch.exe` или
`exch setup` снова: готовые шаги он пропустит.

## 4. Каждый день

- **Запуск** — двойной щелчок по `exch.exe`. **Остановка** — Ctrl+C или закрыть окно (бот
  успевает остановиться штатно; в журнале — `stopped`).
- **Журнал** — папка `logs` рядом с `config.toml`: файл на каждый день, `exch.ГГГГ-ММ-ДД.log`
  (день по UTC), хранятся 14 дней (`keep_days` в `config.toml`). Если что-то пошло не так —
  пришлите файл за этот день.
- **Проверка** — в папке проекта `target\release\exch check`: ✅ готово, ⚠️ стоит поправить,
  ❌ не заработает и что сделать. Можно запускать и при работающем боте.
- Отключите сон ноутбука при работе от сети: уснул — бот молчит до пробуждения.
- Не запускайте `exch` одновременно на двух компьютерах с одним юзерботом.

## 5. Первая настройка в админ-панели

Напишите боту `/start` со своего аккаунта → «Админ-панель».

1. **Капитал.** Пополните кошельки юзербота в CryptoBot и xRocket → «Сверить балансы» →
   «Это мой взнос: провести».
2. **Направления** после установки закрыты: карточка направления → лимиты → «Открыть приём».
3. **Самопроверка** — на каждом кошельке чек на 1 USDT и его же активация. Всё ✅ — можно
   принимать клиентов.

## 6. Обновление

Обновите файлы проекта → `cargo build --release` → перезапустите `exch.exe`. Новые таблицы
применятся сами; данные и настройки остаются.

## 7. Частые проблемы

| Что видно | Что делать |
|---|---|
| «пароль пользователя PostgreSQL не подходит» | `exch setup` — спросит пароль заново |
| «PostgreSQL не запущен» | Службы → `postgresql-x64-16` → Запустить |
| «Telegram не принял токен» | `exch setup` — вставьте токен из @BotFather целиком |
| «Ключ не подходит к сессиям» | верните прежний `SESSION_KEY` в `.env` (копия — `.env.bak`) или войдите юзерботом заново через `exch setup` |
| Установка эмодзи «ждёт N секунд» | это пауза Telegram, установка продолжит сама |
| Бот не отвечает | окно `exch` закрыто или ноутбук уснул; `exch check` покажет, что не так; последние строки — в `logs\exch.<дата>.log` |

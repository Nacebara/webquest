# Логотип и аватарка бота — профессиональная серия (16 ноября 2026, на выбор владельца)

Раунды 1 («eXCH» надписью) и 2 (знаки-линии) — в истории git. Задание владельца 16.11: «хороший
профессиональный логотип в нашем фирменном стиле». Система из трёх частей:

- **знак** — геометрия наших премиум-эмодзи: сетка 24, градиент и стеклянный блик плиток
  (`tools/emoji/icons.js`, `tileBg`), оранжевый `amber` `#CC7300`, ночной `night` `#283050`;
- **словесная часть** — «exch» строчными, Manrope ExtraBold, плотная разрядка;
- **аватарка** — знак во весь круг; в связке со словом — знак на плитке со скруглением 31 %,
  как у наших эмодзи.

на светлом и тёмном, строка в списке чатов в обеих темах. PNG 640×640 — для BotFather.

Анимированная аватарка (Bot API 9.4, `setMyProfilePhoto` + `InputProfilePhotoAnimated`, MPEG4) —
после выбора концепции. Пересобрать: `node render.js` (Playwright; шрифт — `@fontsource/manrope`
в `node_modules` рядом).

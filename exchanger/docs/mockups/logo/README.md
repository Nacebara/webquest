# Аватарка бота — варианты (15 ноября 2026, на выбор владельца)

Просьба владельца: «eXCH» по центру, фон — оранжевый градиент, слегка тёмный, как у наших
премиум-эмодзи. Градиент плиток значков — `tools/emoji/icons.js` (`tileBg`): цвет `amber`
`#CC7300`, сверху слева светлее (+12 %), снизу справа темнее, сверху — стеклянный блик.

(нужен Playwright; шрифты — пакеты @fontsource, лицензия OFL).
